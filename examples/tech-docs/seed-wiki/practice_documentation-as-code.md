文档即代码把文档当作与代码同样的一等交付物：存放在版本库、经评审合入、随版本发布并自动构建。

## 就近编写

文档与代码同仓、按目录关联，随功能变更同步更新，降低文档漂移与过期。

## 结构化与可验证

用 Markdown 加前/后置元数据组织文档，配合自动化检查校验链接、结构与接口一致性。

## 持续发布

文档变更走同样的评审与发布流水线，从源文档构建出面向读者的站点，保证同步与可追溯。
