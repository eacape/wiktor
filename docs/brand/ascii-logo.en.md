# Wiktor ASCII Logo Draft

## A. Primary Visual: Web + W (TUI splash screen, README top)

```
      \  |  /
    .-.\\|//.-.
   (   \\|//   )
  --(--  W  --)--
   (   //|\\   )
    '-'//|\\'-'
      /  |  \
```

Reading: 8 spokes = access protocols; two spiral rings = the compiled knowledge network;
center W = the query-engine hub. The web is derived — delete it and weave a new one.
