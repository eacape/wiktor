# Wiktor ASCII Logo 草稿

## A. 主视觉：蛛网 + W（TUI 启动画面、README 顶部）

```
      \  |  /
    .-.\\|//.-.
   (   \\|//   )
  --(--  W  --)--
   (   //|\\   )
    '-'//|\\'-'
      /  |  \
```

读法：8 根辐条（spokes）= 接入协议；两圈螺旋环 = 编译出的知识网络；
中心 W = 查询引擎中枢。网是派生物——删掉重织一张即可。
